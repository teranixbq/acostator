# Acostator — Data Model

## Entity Overview

```
User
 └─ has many Projects
      └─ has many DatasetRows
           └─ has many Quadruples
                ├─ AspectTerm (span or implicit)
                ├─ OpinionTerm (span or implicit)
                ├─ Category (references CategoryPool)
                └─ Sentiment

Project
 └─ has many Categories (CategoryPool)
```

---

## Entities

### User
```
id           String   @id (from OAuth provider)
github_id    String   @unique
username     String
email        String?
avatar_url   String?
created_at   DateTime
updated_at   DateTime
```

### Project
```
id                String   @id @default(cuid())
user_id           String   (FK → User)
name              String
description       String?
file_name         String   (nama file CSV asli)
file_size         Int      (bytes)
total_rows        Int
status            Enum     (active | archived)
annotation_order  Enum     (sequential | random) @default(sequential)
annotation_queue  String?  (JSON array of row_index, e.g. [42,7,103,...]; null jika sequential)
created_at        DateTime
updated_at        DateTime

// Computed
annotated_rows    Int      (rows where status = completed)
```

### DatasetRow
```
id           String   @id @default(cuid())
project_id   String   (FK → Project)
row_index    Int      (urutan baris dalam CSV, 0-based)
text         String   (isi teks yang akan dianotasi)
status       Enum     (pending | in_progress | completed | skipped)
created_at   DateTime
updated_at   DateTime

@@unique([project_id, row_index])
```

### Quadruple
```
id                String   @id @default(cuid())
row_id            String   (FK → DatasetRow)
project_id        String   (FK → Project, denormalized untuk query efisien)

// Aspect
aspect_term       String   (teks aspect; diisi manual jika implicit)
aspect_implicit   Boolean  @default(false)
aspect_start      Int?     (char offset start; null jika implicit)
aspect_end        Int?     (char offset end; null jika implicit)

// Category
category_id       String   (FK → Category)

// Opinion
opinion_term      String   (teks opinion; diisi manual jika implicit)
opinion_implicit  Boolean  @default(false)
opinion_start     Int?     (char offset start; null jika implicit)
opinion_end       Int?     (char offset end; null jika implicit)

// Sentiment
sentiment         Enum     (positive | negative | neutral)

created_at        DateTime
updated_at        DateTime
```

### Category
```
id           String   @id @default(cuid())
project_id   String   (FK → Project)
name         String   (e.g., "BATTERY", "DISPLAY", "SERVICE")
usage_count  Int      @default(0)  (untuk ranking rekomendasi)
created_at   DateTime

@@unique([project_id, name])
```

## CSV Import Format

File CSV yang di-upload harus memiliki minimal satu kolom teks. Kolom yang wajib ada:

| Kolom | Keterangan |
|---|---|
| `text` atau kolom pertama | Teks yang akan dianotasi |

Kolom lain di CSV akan diabaikan pada import v1, namun disimpan sebagai metadata opsional.

---

## Category Recommendation Logic

Saat annotator memilih category untuk quadruple baru:

1. Ambil semua `Category` dalam project yang sama
2. Urutkan berdasarkan `usage_count DESC` (paling sering dipakai → paling atas)
3. Tampilkan sebagai suggestion list dengan fuzzy search
4. Jika tidak ada yang cocok → allow create new category

---

## Progress Calculation

```
project.annotated_rows = COUNT(DatasetRow WHERE project_id = ? AND status = 'completed')
project.progress_pct   = (annotated_rows / total_rows) * 100
```

---

## Soft Delete Strategy

- Project: soft delete (tambah `deleted_at`)
- DatasetRow: tidak dihapus, hanya status berubah
- Quadruple: hard delete boleh (bisa di-undo via re-annotate)
- Category: soft delete jika `usage_count = 0`, protected jika sedang dipakai
