# Acostator — Product Definition

## Overview

Acostator adalah web-based annotation tool untuk melakukan anotasi manual dataset ABSA (Aspect-Based Sentiment Analysis) menggunakan skema **ACOS (Aspect-Category-Opinion-Sentiment) Quadruple Extraction**.

Tool ini dirancang untuk peneliti dan praktisi NLP yang membutuhkan interface yang efisien untuk membuat ground-truth dataset ACOS secara manual.

---

## Problem Statement

Membuat dataset ACOS secara manual sangat tedious karena setiap teks bisa memiliki banyak quadruple, dan tidak ada tool yang dirancang khusus untuk alur kerja ini. Spreadsheet tidak cukup — annotator butuh interface yang bisa highlight span teks, track progress, dan export dalam format standar.

---

## Target User

Peneliti NLP / mahasiswa yang melakukan penelitian ABSA dan membutuhkan ground-truth dataset ACOS.

---

## Core Concepts

### ACOS Quadruple
Setiap teks dapat memiliki satu atau lebih quadruple:

| Elemen | Deskripsi | Tipe |
|---|---|---|
| **Aspect Term** | Kata/frasa di teks yang menjadi subjek sentimen | Span teks atau Implicit |
| **Category** | Kategori aspek (e.g., BATTERY, DISPLAY, SERVICE) | Predefined + extensible |
| **Opinion** | Kata/frasa di teks yang mengekspresikan opini | Span teks atau Implicit |
| **Sentiment** | Polaritas sentimen | Positive / Negative / Neutral / Mixed |

### Implicit
Ketika Aspect atau Opinion tidak muncul secara eksplisit di teks, annotator tetap wajib mendefinisikan semua elemen ACOS secara manual (tidak bisa di-skip).

### Text Column
Saat upload CSV, user memilih kolom mana yang berisi teks untuk dianotasi. Ini disimpan sebagai `text_column` pada project dan dipakai untuk parse baris CSV di browser.

## User Flow

### 1. Auth
- Login via GitHub OAuth
- Satu akun = satu user, tidak ada role/permission tambahan untuk saat ini

### 2. Project Management
- User bisa membuat banyak project
- Satu project = satu dataset CSV (max 1GB)
- Project menampilkan progress: berapa row sudah dianotasi vs total
- Urutan anotasi bisa dikonfigurasi per project:
  - **Sequential** (default) — row ditampilkan sesuai urutan CSV, mulai dari index 0
  - **Random** (opsional) — row ditampilkan dalam urutan acak, berguna untuk mengurangi bias posisional dalam anotasi

### 3. Upload CSV dengan Column Picker
```
User pilih file CSV
  → Browser parse header row secara lokal (belum upload)
  → User pilih kolom mana yang berisi teks anotasi (text_column)
  → Browser upload file langsung ke R2 via presigned URL
  → Worker catat text_column pada project
  → CSV tetap di R2 secara permanen
```

### 4. Annotation Flow (per row)
```
Buka row
  └─ Highlight Aspect Term di teks (klik+drag)
      ├─ [atau] Mark as Implicit → input teks aspect manual
      └─ Setelah aspect dipilih:
          └─ Highlight Opinion di teks (klik+drag)
              ├─ [atau] Mark as Implicit → input teks opinion manual
              └─ Setelah opinion dipilih:
                  └─ Pilih Sentiment (Positive / Negative / Neutral / Mixed)
                      └─ Pilih atau buat Category
                          └─ Add Annotation → disimpan lokal
```

Bisa tambah beberapa quadruple per row sebelum complete.

### 5. Penyimpanan Anotasi Lokal-First
- Semua pekerjaan anotasi dilakukan di browser
- Baris CSV di-cache di IndexedDB setelah fetch pertama
- Anotasi pending disimpan di IndexedDB dan in-memory
- Navigasi (Previous/Next) sepenuhnya lokal — tanpa API call
- Saat "Complete": anotasi di-sync ke D1 via POST (upsert)

### 6. Navigasi Progress
- **Next** — maju ke row berikutnya (tandai row saat ini completed jika ada anotasi)
- **Previous** — kembali ke row sebelumnya (load dari cache IndexedDB)
- **Complete** — eksplisit sync anotasi row saat ini ke server
- Indikator sync status: idle / syncing / synced / error

### 7. Export
- JSON export: satu entry per row, dengan array quadruple
- CSV export: satu baris per quadruple, di-join dengan teks CSV asli


## Scope (v1)

### In Scope
- GitHub OAuth login
- Multi-project per user
- Upload CSV dataset (max 1GB) dengan column picker
- Annotation interface dengan text highlighting dan seleksi span
- Implicit aspect/opinion support
- Category management dengan rekomendasi dari history
- Progress tracking per project dan per row
- Mode urutan anotasi: sequential (default) atau random (opsional)
- Anotasi lokal-first dengan cache IndexedDB
- Sync ke D1 saat Complete (upsert, idempotent)
- Export JSON dan CSV

### Out of Scope (v1)
- Multi-annotator / project sharing
- Inter-annotator agreement (IAA)
- Review / adjudication workflow
- Format input selain CSV
- Model-assisted pre-annotation
- Real-time collaboration
