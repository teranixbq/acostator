# Acostator — Database Schema

## Entity Overview

```
User
 └─ has many Projects
      └─ has many DatasetRows
           └─ has many Quadruples
                ├─ AspectTerm (span or implicit)
                ├─ OpinionTerm (span or implicit)
                ├─ Category (references CategoryPool)
                └─ Sentiment

Project
 └─ has many Categories (CategoryPool)
```

---

## Entities

### User
```
id           String   @id (from OAuth provider)
github_id    String   @unique
username     String
email        String?
avatar_url   String?
created_at   DateTime
updated_at   DateTime
```

### Project
```
id                String   @id @default(cuid())
user_id           String   (FK → User)
name              String
description       String?
file_name         String   (original CSV filename)
file_size         Int      (bytes)
total_rows        Int
status            Enum     (active | archived)
annotation_order  Enum     (sequential | random) @default(sequential)
annotation_queue  String?  (JSON array of row_index, e.g. [42,7,103,...]; null if sequential)
created_at        DateTime
updated_at        DateTime

// Computed
annotated_rows    Int      (rows where status = completed)
```

### DatasetRow
```
id           String   @id @default(cuid())
project_id   String   (FK → Project)
row_index    Int      (row order in CSV, 0-based)
text         String   (text content to be annotated)
status       Enum     (pending | in_progress | completed | skipped)
created_at   DateTime
updated_at   DateTime

@@unique([project_id, row_index])
```

### Quadruple
```
id                String   @id @default(cuid())
row_id            String   (FK → DatasetRow)
project_id        String   (FK → Project, denormalized for efficient queries)

// Aspect
aspect_term       String   (aspect text; entered manually if implicit)
aspect_implicit   Boolean  @default(false)
aspect_start      Int?     (char offset start; null if implicit)
aspect_end        Int?     (char offset end; null if implicit)

// Category
category_id       String   (FK → Category)

// Opinion
opinion_term      String   (opinion text; entered manually if implicit)
opinion_implicit  Boolean  @default(false)
opinion_start     Int?     (char offset start; null if implicit)
opinion_end       Int?     (char offset end; null if implicit)

// Sentiment
sentiment         Enum     (positive | negative | neutral)

created_at        DateTime
updated_at        DateTime
```

### Category
```
id           String   @id @default(cuid())
project_id   String   (FK → Project)
name         String   (e.g., "BATTERY", "DISPLAY", "SERVICE")
usage_count  Int      @default(0)  (used for recommendation ranking)
created_at   DateTime

@@unique([project_id, name])
```

---

## CSV Import Format

The uploaded CSV file must have at least one text column. Required column:

| Column | Description |
|---|---|
| `text` or the first column | Text content to be annotated |

Other columns in the CSV will be ignored on v1 import but stored as optional metadata.

---

## Category Recommendation Logic

When an annotator selects a category for a new quadruple:

1. Fetch all `Category` records within the same project
2. Sort by `usage_count DESC` (most used → top of list)
3. Display as a suggestion list with fuzzy search
4. If no match found → allow creating a new category

---

## Progress Calculation

```
project.annotated_rows = COUNT(DatasetRow WHERE project_id = ? AND status = 'completed')
project.progress_pct   = (annotated_rows / total_rows) * 100
```

---

## Soft Delete Strategy

- Project: soft delete (add `deleted_at`)
- DatasetRow: not deleted, only status changes
- Quadruple: hard delete is fine (can be undone via re-annotation)
- Category: soft delete if `usage_count = 0`, protected if currently in use
