# Acostator — Database Schema

## Entity Overview

```
User
 └─ has many Projects
      └─ has many Annotations (Quadruples)
           ├─ AspectTerm (span or implicit)
           ├─ OpinionTerm (span or implicit)
           ├─ Category (references CategoryPool)
           └─ Sentiment

Project
 └─ has many Categories (CategoryPool)
```

Note: `DatasetRow` no longer exists as a D1 table. CSV rows are stored in R2 (as the original file) and cached in the browser's IndexedDB. Only quadruples are stored in D1.

---

## Entities

### User
```
id           String   @id (from OAuth provider)
github_id    String   @unique
username     String
email        String?
avatar_url   String?
created_at   DateTime
updated_at   DateTime
```

### Project
```
id                String   @id @default(cuid())
user_id           String   (FK → User)
name              String
description       String?
file_name         String   (original CSV filename)
file_size         Int      (bytes)
total_rows        Int
text_column       String   (CSV column name selected by user as annotation text source)
status            Enum     (active | archived)
annotation_order  Enum     (sequential | random) @default(sequential)
annotation_queue  String?  (JSON array of row_index, e.g. [42,7,103,...]; null if sequential)
created_at        DateTime
updated_at        DateTime

// Computed
annotated_rows    Int      (count of distinct row_index in annotations table)
```

### Annotation (Quadruple)
```
id                String   @id @default(cuid())
project_id        String   (FK → Project)
row_index         Int      (0-based row index in CSV — joins to R2/IDB data)

// Aspect
aspect_term       String   (aspect text; entered manually if implicit)
aspect_implicit   Boolean  @default(false)
aspect_start      Int?     (char offset start in row text; null if implicit)
aspect_end        Int?     (char offset end in row text; null if implicit)

// Category
category_id       String   (FK → Category)

// Opinion
opinion_term      String   (opinion text; entered manually if implicit)
opinion_implicit  Boolean  @default(false)
opinion_start     Int?     (char offset start in row text; null if implicit)
opinion_end       Int?     (char offset end in row text; null if implicit)

// Sentiment
sentiment         Enum     (positive | negative | neutral | mixed)

created_at        DateTime
updated_at        DateTime

@@unique([project_id, row_index, aspect_term, opinion_term])
```

The UNIQUE constraint prevents duplicate quadruples for the same (project, row, aspect, opinion) combination. POST endpoint uses upsert (INSERT OR REPLACE) to handle re-submissions safely.

### Category
```
id           String   @id @default(cuid())
project_id   String   (FK → Project)
name         String
usage_count  Int      @default(0)
created_at   DateTime
updated_at   DateTime

@@unique([project_id, name])
```

## What is NOT in D1

| Data | Where it lives |
|---|---|
| CSV file (raw) | R2 (permanent, key: `projects/{id}/data.csv`) |
| CSV rows (parsed) | Browser IndexedDB (`csv_rows` store) |
| Current row index | Browser IndexedDB (`progress` store) |
| Row completion status | Browser IndexedDB (`row_statuses` store) |
| Pending (unsaved) annotations | Browser memory + IndexedDB (`annotations` store) |

## IndexedDB Schema (Browser)

DB name: `acostator-{projectId}`

| Store | Key | Value |
|---|---|---|
| `csv_rows` | `row_index` | `{ row_index: number, text: string }` |
| `progress` | `"last"` | `{ last_row_index: number }` |
| `row_statuses` | `row_index` | `"pending" \| "completed" \| "skipped"` |
| `annotations` | `[row_index, localId]` | `IdbAnnotationRecord` |

## Category Recommendation Logic

When an annotator selects a category for a new quadruple:

1. Fetch all `Category` records within the same project
2. Sort by `usage_count DESC` (most used → top of list)
3. Display as a suggestion list with fuzzy search
4. If no match found → allow creating a new category

---

## Progress Calculation

```
project.annotated_rows = COUNT(DISTINCT row_index WHERE project_id = ?)
project.progress_pct   = (annotated_rows / total_rows) * 100
```

---

## Soft Delete Strategy

- Project: soft delete (add `deleted_at`)
- Annotation: hard delete is fine (can be undone via re-annotation)
- Category: soft delete if `usage_count = 0`, protected if currently in use
